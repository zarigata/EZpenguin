01 / A smaller starting point

Less OS to manage.
More room to build.

Start with a minimal system, then add the pieces you need. Plain Bash tools and Debian packages keep the moving parts easy to understand.

[ 01 ]

A home for your homelab.

Set up containers, web servers, databases, file sharing, and monitoring from one software menu. Useful tools, without hunting down every package.

What is EZpenguin?

EZpenguin is a lightweight Linux distribution built on Debian 12 (bookworm). It adds first-boot setup, a 61-entry software catalog, and Bash tools for configuration, updates, backups, and diagnostics.

What hardware can run it?

The build targets amd64 PCs with BIOS or UEFI and ARM64 systems with UEFI. Board-specific boot support and broad real-hardware validation are not complete. Test your hardware in a safe environment first; see the roadmap for current goals.

Does it come with a desktop?

The base system is minimal and terminal-focused. XFCE and LXDE are optional catalog entries. Install a desktop with sudo ez-software install xfce or sudo ez-software install lxde; additional packages need disk space and memory.

Is EZpenguin ready for production?

EZpenguin is at v1.1.0. The repository includes rootfs checks and QEMU tests, but wider hardware validation, artifact signing, and further hardening remain roadmap work. Evaluate it in a VM or a spare machine before relying on it.

Is it free and open source?

Yes. EZpenguin's code is available under GPL-3.0-or-later. Included packages retain their own licenses. You can inspect the source, build images, report bugs, and contribute improvements on GitHub.
