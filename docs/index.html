03 / Give the penguin a home

Your next project
starts with a boot.

Choose the route that fits your machine. Start in a disposable VM if you are exploring. Back up anything you want to keep before installation.

A clean start for your hardware.

v0.4.1 images are available on GitHub Releases.

  1. Choose amd64 for x86-64 PCs, or arm64 for compatible UEFI ARM64 systems.
  2. Download the matching .img.xz, decompress it if your flashing tool requires it, and write it to the target drive.
  3. Boot the machine and follow the first-boot wizard.

Flashing erases the selected drive. ARM64 support does not imply support for every single-board computer.

Boot first. Install when ready.

Use the amd64 live ISO with a virtual machine or a USB drive on an x86-64 PC. It supports BIOS and UEFI boot.

  1. Download the ISO and attach it to your VM, or write it to a USB drive.
  2. Boot the live environment.
  3. Choose disk installation in the wizard, or stay in the live session. Run sudo ez-install to install later.

Writing the USB erases it. Installing to a disk erases the selected target disk.

Download amd64 ISO ↓

Download. Review. Install.

Run from a Debian / Ubuntu environment with curl, tar, and xz available. Review the script before granting root privileges.

curl -fsSL https://raw.githubusercontent.com/zarigata/EZpenguin/main/installer/online-installer.sh -o ezpenguin-install.sh
less ezpenguin-install.sh
sudo bash ezpenguin-install.sh

Containers convert in place, replacing the userland. Regular machines, including VMs, use target-disk installation by default and erase that disk. The installer may reboot the machine or stop the container.

04 / Good questions

Before you
take the plunge.

More details in the project documentation ↗

What is EZpenguin?

EZpenguin is a lightweight Linux distribution built on Debian 12 (bookworm). It adds first-boot setup, a 61-entry software catalog, and Bash tools for configuration, updates, backups, and diagnostics.

What hardware can run it?

The build targets amd64 PCs with BIOS or UEFI and ARM64 systems with UEFI. Board-specific boot support and broad real-hardware validation are not complete. Test your hardware in a safe environment first; see the roadmap for current goals.

Does it come with a desktop?

The base system is minimal and terminal-focused. XFCE and LXDE are optional catalog entries. Install a desktop with sudo ez-software install xfce or sudo ez-software install lxde; additional packages need disk space and memory.

Is EZpenguin ready for production?

EZpenguin is an early-stage v0.4.1 project. The repository includes rootfs checks and QEMU tests, but wider hardware validation, artifact signing, and further hardening remain roadmap work. Evaluate it in a VM or a spare machine before relying on it.

Is it free and open source?

Yes. EZpenguin's code is available under GPL-3.0-or-later. Included packages retain their own licenses. You can inspect the source, build images, report bugs, and contribute improvements on GitHub.
