🚀Install EZpenguin on anything — one line

Works on running Ubuntu/Debian systems and Docker containers. No ISO. No USB. Converts in place and reboots into the penguin.

bash -c "$(curl -sSfL https://raw.githubusercontent.com/zarigata/EZpenguin/main/installer/online-installer.sh)"

The installer detects container vs bare-metal, picks amd64/arm64, downloads the latest release, converts (or partitions a target disk on metal), and reboots automatically.

$ docker run -d --name demo ubuntu:24.04 sleep infinity
$ docker exec -it demo bash -c 'apt-get update -qq && apt-get install -y -qq curl xz-utils'
$ docker exec -it demo bash -c "$(curl -sSfL .../online-installer.sh)"

🪄Three ways to penguin

  1. One-liner — convert a running system or container in place, DietPi-style. No media needed.
  2. Flash & boot — dd the hybrid image to USB; boots BIOS or UEFI, wizard auto-expands the disk.
  3. Live ISO installer — boot the ISO, pick "Install EZpenguin to a disk", reboot. Done.

🧙Zero-touch or classic wizard — your call

🧙Headless firstboot.conf

Drop a key=value file on the disk: user, password, SSH, timezone, hostname. Boots, configures itself in 80 seconds, reboots ready. No keyboard, no monitor.

🖥️Interactive wizard

Classic tty1 walkthrough: locale, timezone, keymap, hostname, user, SSH — with optional DietPi-style global password for user+root.

🔧Full toolset

ez-doctor health check · ez-net diagnostics · ez-config settings · ez-backup · fastfetch-style ez-info. Plain bash, fully auditable.
