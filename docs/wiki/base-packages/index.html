Base image package reference

The build explicitly requests 59 base packages before dependencies and cleanup. These are separate from the 61 optional catalog recipes. The installed package count is larger because Debian resolves dependencies.

Architecture mapping: ARM64 replaces linux-image-amd64 with linux-image-arm64, uses ARM64 EFI GRUB packages, and omits grub-pc-bin. This reference starts from the common amd64-oriented base list.

Deliberately excluded packages

The cleanup list excludes the following explicit packages. This keeps the base small; local manpages are therefore not guaranteed.

  • man-db
  • manpages
  • manpages-dev
  • tasksel
  • tasksel-data
  • debconf-i18n
  • poppler-data
  • iso-codes

Inspect your actual machine

dpkg-query -W
apt-cache policy PACKAGE_NAME

The package database on your running machine is authoritative for its installed versions. This list is a build specification, not a claim that every package is present in every historical release artifact.
