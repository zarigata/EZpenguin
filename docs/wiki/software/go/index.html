Go toolchain

Compile Go applications with the Debian Go toolchain.

DevelopmentCatalog ID: goOptional recipe

Install on EZpenguin

Run this command in your EZpenguin terminal. The browser only copies commands; it does not administer your system.

sudo ez-software install go

Packages requested by this recipe

PackageReference
golangDebian package reference ↗

These are the explicit package names in the recipe, not a complete dependency list. APT resolves dependencies and selects versions from your configured repositories.

What happens after installation

No extra post-install shell hook is defined for this entry. Package-maintainer scripts can still perform their normal Debian setup. Configure the software for your use case before relying on it.

First steps and verification

go version
go env GOPATH

Run the examples one at a time. Replace uppercase placeholders with values for your system. These commands have not been executed against every installed stack as part of this website update.

Configuration and data

Use go.mod and go.sum in each module.

Operational notes

Verify the compiler version before building a module that requires a newer Go release.

If something fails

Read the troubleshooting guide. Start with apt-cache policy for the requested packages, then inspect the named service and its journal where relevant. Application data is not included automatically in ez-backup configuration archives.
